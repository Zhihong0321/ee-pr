📌 Overview & Execution Pipeline

When an email arrives at pr@eternalgy.me, pr@eternalgy.com, or any corporate press address, your EE-Mail server dispatches an HTTP POST webhook notification to the PR AI server.

Automatic Execution Steps:
  1. EE-Mail Server sends POST request to /webhook/email-received.
  2. PR AI immediately calls EE-Mail API POST /received-emails/fetch with {"email_id": email_id}.
  3. EE-Mail Server populates full email content, attachments, and marks email as read.
  4. PR AI categorizes content (CERTIFICATE_UPDATE, PRESS_RELEASE, AWARD) and queues it for manager approval.

POST Inbound Email Webhook Endpoint

https://ee-pr-production.up.railway.app/webhook/email-received

Request Headers

Content-Type: application/json

JSON Payload Fields

Field Name Type Required Description
email_id / id String / Integer REQUIRED Unique email ID on the EE-Mail server (e.g. "589112fd-439f-4213-9343-5192a759ec87" or 2110).
from String Optional Sender email address (e.g. "noreply@seda.gov.my").
subject String Optional Email subject line (e.g. "ATP202617521: Approval for eATAP Application").
to Array of Strings Optional Recipient email addresses (e.g. ["pr@eternalgy.me"]).

Sample Webhook Request Payload

{
  "email_id": "589112fd-439f-4213-9343-5192a759ec87",
  "from": "noreply@seda.gov.my",
  "to": ["pr@eternalgy.me"],

}

Node.js / Express Dispatch Example

const fetch = require('node-fetch');

async function notifyPRAI(receivedEmail) {
  try {
    const response = await fetch('https://ee-pr-production.up.railway.app/webhook/email-received', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        email_id: receivedEmail.email_id || receivedEmail.id,
        from: receivedEmail.from,
        to: receivedEmail.to,
        subject: receivedEmail.subject
      })
    });
    const result = await response.json();
    console.log('PR AI Webhook Response:', result);
  } catch (error) {
    console.error('Webhook error:', error);
  }
}
